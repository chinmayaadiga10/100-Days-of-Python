# 🍅 Day 28 - Pomodoro Timer

A desktop productivity application built with **Tkinter** that implements the **Pomodoro Technique**. The timer alternates between work sessions and breaks while visually tracking completed work intervals. This project is part of **Day 28** of the **100 Days of Code: Python Bootcamp**.

---

## 📂 Project Structure

```text
day028/
│── main.py
│── tomato.png
└── README.md
```

---

## 🚀 Features

- 25-minute work sessions
- Short and long break timers
- Automatic session switching
- Countdown timer
- Start and Reset functionality
- Progress tracking with checkmarks
- GUI built using Tkinter and Canvas
