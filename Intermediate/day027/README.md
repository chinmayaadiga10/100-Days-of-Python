# 🚗 Day 27 - Miles to Kilometers Converter

A simple desktop GUI application built with **Tkinter** that converts distances from **miles to kilometers**. This project marks the introduction to building graphical user interfaces (GUIs) in Python as part of **Day 27** of the **100 Days of Code: Python Bootcamp**.

---

## 🚀 Features

- Convert miles to kilometers
- Simple and intuitive GUI
- User input using an Entry widget
- Displays the converted value instantly
- Calculate button to perform the conversion

---

## 🛠️ Concepts Used

- TKinter
- Labels
- Entry Widgets
- Buttons
- Grid Layout Manager
- Event Handling
- Functions

---

## 📖 What I Learned

- Creating desktop applications with Tkinter
- Positioning widgets using the `grid()` layout manager
- Handling user input through Entry widgets
- Updating Label widgets dynamically
- Connecting buttons to functions using the `command` parameter
