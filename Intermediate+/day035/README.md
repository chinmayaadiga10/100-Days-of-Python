# 🌧️ Day 35 - Rain Alert

A Python program that uses the **OpenWeatherMap API** to check the weather forecast and determine whether rain is expected. If rain is forecast, the program advises the user to carry an umbrella.

---

## 📂 Project Structure

```text
day035/
│── main.py
└── README.md
```

---

## 🚀 Features

- Fetches weather forecast data using an API
- Uses latitude and longitude to get location-specific weather
- Checks weather condition codes
- Detects whether rain is expected
- Displays an umbrella reminder
- Stores the API key using an environment variable
