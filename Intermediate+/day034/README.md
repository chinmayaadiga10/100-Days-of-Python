# 🧠 Day 34 - Quizzler App

A GUI-based **True/False Quiz application** built with Python and Tkinter. The project uses a question bank, separates the quiz logic from the user interface, and keeps track of the user's score.

## 🚀 Features

- True/False quiz questions
- Graphical interface using Tkinter
- Score tracking
- Question counter
- Correct/incorrect answer feedback
- Questions loaded from a data source
- Separate modules for quiz logic and UI

## 🧩 Project Structure

The application is divided into separate components:

- `question_model.py` — Defines the `Question` class
- `quiz_brain.py` — Handles questions, scoring and quiz logic
- `data.py` — Stores the quiz question data
- `ui.py` — Builds and manages the Tkinter interface
- `main.py` — Connects all components together
